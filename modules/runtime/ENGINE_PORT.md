# Porting modules/runtime to the current engine

The runtime was written against engine `7799a85`. These are the public declarations of the
engine modules it imports that changed or disappeared since then, generated by diffing
`7799a85:src/<module>.silk` with `HEAD:modules/engine/src/<module>.silk`. Items the runtime
source mentions by name are marked **used**; generic names (`make`, `value`, ...) are marked
by spelling only, so treat the mark as a hint.

The dominant change is the engine moving from raw `ValueBits` to owned `Value` / borrowed
`ValueRef<'a>`; the runtime mentions `ValueBits` on about 1,400 lines in 49 files.

121 declarations changed; 55 are spelled somewhere in the runtime.
